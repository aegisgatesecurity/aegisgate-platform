# Models withdrawn (2026-11-23)

All model artifacts previously vendored here were withdrawn and moved to an
offline audit archive (`poisoned-model-archive-2026-11-23`). The CharCNN-BiLSTM
lineage (v2–v22b), DeBERTa, and RoBERTa models were trained on a corpus whose
attack-side labels failed audit. Do not add model files here until a
re-baselined model ships with a signed retraining report. See
docs/ML-WITHDRAWN.md.
