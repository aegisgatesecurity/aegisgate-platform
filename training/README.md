# AegisGate ML Training

Character-level CNN-BiLSTM with Attention for adversarial prompt detection.

## Quick Start

```bash
# 1. Generate training data from Go pipeline
cd /path/to/aegisgate-platform
go run pkg/ml/training/augment.go -output training/data/

# 2. Train the model
python training/train.py --data-dir training/data/ --epochs 50

# 3. Export to ONNX
python training/export_onnx.py --checkpoint training/checkpoints/best_model.pt --output pkg/ml/models/threat_cnn_bilstm.onnx
```

## Architecture

```
Input: [batch, 128] int32 (ASCII character IDs)
  → Embedding(128 vocab → 64 dim)
  → Conv1D(filters=256, kernel_sizes=[3,5,7], parallel branches)
  → BatchNorm → Concatenate
  → BiLSTM(128 hidden, 2 layers)
  → Attention (learned weights)
  → Dense(64, ReLU) → Dropout(0.3) → Dense(1, Sigmoid)
  → Output: [batch, 1] float32 (threat score [0, 1])
```

Parameters: ~1.6M | ONNX size: ~6MB | Inference: <1ms on CPU

## Files

- `model.py` — Model definition (ThreatCNNBiLSTM)
- `train.py` — Training script with focal loss, cosine annealing, zero-FPR tracking
- `export_onnx.py` — ONNX export with verification and model card generation

## Requirements

- Python 3.12+
- PyTorch 2.x
- ONNX 1.22+
- onnxruntime 1.27+
- scikit-learn (for metrics)

## Target Metrics

| Metric | Target | Description |
|--------|--------|-------------|
| FPR | 0.0% | Zero false positives on benign traffic |
| Detection (gap) | >95% | On char_transpose, char_delete_vowels, char_reverse_words |
| Latency | <1ms | Per inference on CPU |
| Model size | <10MB | ONNX format |

## Data Pipeline

Training data is generated by `pkg/ml/training/augment.go`:
- 12,752 examples total (2,214 adversarial + 10,538 benign)
- Train/val/test: 10,201 / 1,275 / 1,276

## Integration

The ONNX model integrates with the Go proxy via:
- `pkg/ml/detector.go` — ThreatDetector with ONNX-ready interface
- `pkg/ml/normalizer.go` — CharNormalizer (128 chars, ASCII, PAD=0, UNK=1)
- `pkg/ml/calibration.go` — Zero-FPR threshold calibration

Feature flags (cold-start deployment):
- `ml_threat_detection_enabled: false` (disabled by default)
- `ml_shadow_mode: true` (log predictions, don't block)
